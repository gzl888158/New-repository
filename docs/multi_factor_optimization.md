# 多因子与回测体系优化 - 问题诊断与优化方案

## 一、问题诊断清单

### 1. 多因子模块问题

#### P0 - 严重问题
- [x] **缺失因子计算模块**: 原项目无A股多因子选股模块，已新建 `analysis/multi_factor/`
- [x] **因子类别不完整**: 需覆盖价值、质量、动量、规模、量价、事件6大类
- [x] **因子方向未统一**: 部分因子越小越好（如负债率），需统一为越大越好
- [x] **缺失因子标准化**: 需实现MAD去极值 + z-score标准化

#### P1 - 重要问题
- [x] **缺失IC分析**: 无法评估因子预测能力
- [x] **缺失共线性检测**: 因子间可能高度相关，导致信息冗余
- [x] **缺失因子衰减测试**: 无法判断因子有效期
- [x] **缺失因子稳定性评估**: 需计算IC IR、换手率等指标

#### P2 - 优化项
- [x] **缺失行业中性化**: 因子可能受行业分布影响
- [x] **缺失因子加权优化**: 仅支持等权，需支持IC加权、优化加权

### 2. 回测模块问题

#### P0 - 严重问题
- [x] **缺失股票回测引擎**: 原项目仅有加密货币回测，需新建A股回测引擎
- [x] **缺失股票池过滤**: 未剔除ST、新股、停牌股票
- [x] **缺失交易成本**: 未计算手续费、滑点、印花税
- [x] **缺失基准对比**: 无法对比沪深300/中证500

#### P1 - 重要问题
- [x] **未来函数风险**: 财务数据使用发布时间而非报告期，可能引入未来信息
- [x] **幸存者偏差**: 未包含退市股票，高估策略收益
- [x] **缺失样本外测试**: 无walk-forward分析，过拟合风险高

#### P2 - 优化项
- [x] **缺失数据窥探检测**: 未进行多重检验校正
- [x] **缺失调仓调度**: 未实现月度/季度调仓逻辑

## 二、优化方案

### 1. 多因子模块优化

#### 1.1 因子计算引擎 (`factor_engine.py`)
- **实现6大类因子**:
  - 价值: EP (E/P), BP (B/P)
  - 质量: ROE, 资产负债率
  - 动量: 20日收益率
  - 规模: 对数市值
  - 量价: 换手率, 波动率
  - 事件: 业绩超预期 (简化为同比增速)

- **因子标准化流程**:
  1. MAD去极值 (3倍中位数绝对偏差)
  2. z-score标准化
  3. 缺失值填充为0

- **避免未来函数**:
  - 财务数据使用point-in-time (发布日期 <= 交易日期)
  - 价格数据使用前复权

#### 1.2 因子分析器 (`factor_analyzer.py`)
- **IC分析**:
  - Rank IC (Spearman相关)
  - 滚动IC (时变IC)
  - IC IR (IC均值/IC标准差)
  - IC > 0 比例

- **共线性检测**:
  - 相关矩阵 (Spearman)
  - VIF (方差膨胀因子)
  - 高相关性因子对识别 (阈值0.7)

- **因子衰减测试**:
  - 不同持有期IC (1/5/10/20日)
  - 因子换手率 (选股稳定性)

#### 1.3 选股器 (`stock_selector.py`)
- **因子打分**:
  - 调整因子方向 (统一为越大越好)
  - 加权求和 (等权/IC加权/优化加权)

- **选股逻辑**:
  - Top-N: 选前N只
  - 阈值: 得分 > 阈值

- **行业中性化** (可选):
  - 行业内z-score标准化

### 2. 回测模块优化

#### 2.1 股票回测引擎 (`stock_backtest_engine.py`)
- **股票池过滤**:
  - 剔除ST/*ST
  - 剔除上市不足60天新股
  - 剔除停牌股票

- **调仓调度**:
  - 月度调仓 (每月同一天)
  - 季度调仓 (每3个月)

- **交易成本**:
  - 佣金: 0.1% (双边, 最低5元)
  - 滑点: 0.1%
  - 印花税: 0.1% (仅卖出)

- **绩效评估**:
  - 年化收益率
  - 年化波动率
  - 夏普比率 (无风险利率3%)
  - 最大回撤
  - Calmar比率
  - 超额收益 (vs 基准)

#### 2.2 偏差防范 (`bias_prevention.py`)
- **未来函数检测**:
  - 检查数据发布时间 vs 交易时间
  - 输出违规报告

- **幸存者偏差调整**:
  - 包含历史退市股票
  - 调整股票池

- **数据窥探检测**:
  - Bonferroni校正 (严格)
  - FDR校正 (宽松)
  - Deflated Sharpe Ratio
  - 过拟合概率估计

- **Walk-Forward分析**:
  - 滚动样本外测试
  - 训练窗口: 3年
  - 测试窗口: 1年
  - 步进: 1年

## 四、自测校验清单

### 1. 因子计算校验
- [ ] 因子方向正确 (价值因子越大越好，负债率越小越好)
- [ ] 因子标准化后均值为0，标准差为1
- [ ] 缺失值处理正确 (填充为0或中位数)
- [ ] 无未来函数 (财务数据发布日期 <= 交易日期)

### 2. 因子分析校验
- [ ] IC计算正确 (Spearman/ Pearson相关)
- [ ] IC IR > 0.5 为有效因子
- [ ] 共线性检测正确 (VIF < 10)
- [ ] 因子衰减测试覆盖多个持有期

### 3. 选股逻辑校验
- [ ] 因子加权求和正确
- [ ] Top-N选股正确 (按得分排序)
- [ ] 行业中性化后因子在行业内标准化

### 4. 回测校验
- [ ] 股票池过滤正确 (剔除ST、新股、停牌)
- [ ] 交易成本计算正确 (佣金+滑点+印花税)
- [ ] 调仓日期正确 (月度/季度)
- [ ] 绩效指标计算正确 (年化、夏普、最大回撤)

### 5. 偏差防范校验
- [ ] 未来函数检测覆盖所有数据点
- [ ] 幸存者偏差调整包含退市股票
- [ ] 多重检验校正正确 (Bonferroni/FDR)
- [ ] Walk-Forward样本外测试独立

### 6. 代码质量校验
- [ ] 代码可复现 (固定随机种子)
- [ ] 无硬编码参数 (可配置)
- [ ] 异常处理完善 (缺失数据、网络错误)
- [ ] 日志完整 (关键步骤有日志)

## 六、注意事项

1. **数据质量**: AKShare数据可能有延迟或缺失，生产环境需备用数据源
2. **性能优化**: 全市场因子计算较慢，建议分批处理或使用多进程
3. **参数调优**: 因子窗口、调仓频率等参数需根据实际回测结果调整
4. **风险控制**: 回测收益不代表未来表现，需结合风险管理
5. **合规要求**: 实盘交易需遵守交易所规则，注意持仓限制

## 七、后续优化方向

1. **因子挖掘**: 接入机器学习自动发现有效因子
2. **动态加权**: 根据市场状态动态调整因子权重
3. **高频因子**: 加入日内量价因子 (分钟级)
4. **另类数据**: 接入舆情、供应链、专利等另类数据
5. **组合优化**: 使用均值-方差优化或风险平价模型
6. **实盘对接**: 对接券商API实现自动化交易
