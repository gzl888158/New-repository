## 四、核心发现

### 1. 手续费磨损是 grid 的次要矛盾（与 scalping 本质不同）

grid 的止盈 2.0% 是往返手续费 0.1% 的 **20 倍**，而 scalping 的止盈 0.8% 仅是手续费的 8 倍。因此 grid 不会像 scalping 那样被手续费"直接磨死"：

- 场景①（裸网格）手续费/毛盈利 = 0.67，看似很高，但根因是**毛盈利本身趋近于零**（147 笔里 130 笔止损），而非手续费过高。
- 场景②（生产门槛）手续费/毛盈利 = **0.06**，手续费仅吃掉 6% 毛盈利，完全可控。

**结论：grid 的优化重点不是"降手续费/调间距"，而是"提升信号胜率"。**

### 2. 裸网格均值回归的胜率极低（10%–19%），远低于盈亏平衡线

对称止盈/止损（±2%）下的盈亏平衡胜率约 52.5%（含手续费）。但裸网格胜率仅 0%–19%：

- XRP / DOGE 连续 24 笔**全部止损**，胜率 0%。
- 说明"EMA20 ±3% 带"在 1H 粒度上捕捉到的是**趋势延续（追跌/追涨）**，而非均值回归——价格下探 3% 带后继续下破 2% 止损的概率远高于反弹 2% 止盈。

这正是生产 `GridStrategy` 必须叠加 `_confirm_grid_entry`（趋势方向过滤）、`_check_trend_ready_for_entry`（P33 ADX 门禁）、5 维信号质量评分的原因——**裸网格信号本身就是垃圾**。

### 3. 信号质量门槛 0.35 是 grid 盈亏的分水岭

注入 `min_signal_quality = 0.35` 后：交易数 147 → 24（-84%），净盈亏 -449.70 → **+153.46**，胜率 14% → 81%–100%。

- 这印证了既有经验：**grid 的 `min_signal_quality` 硬下限 0.35 不可下调**，它是把裸信号垃圾提纯成有效信号的核心过滤器。
- 本回测用 `evaluate_signal_quality`（8 指标）近似生产 5 维评分，属于**简化近似**，方向结论可靠、绝对数值偏乐观。

### 4. `stop_loss_pct` 与 `max_stop_loss_pct` 存在配置冲突（已修复）

config 中 `stop_loss_pct = 0.078` 被列入 `locked_params`（锁定），但 `_trigger_grid_order` 内 `min(stop_loss_pct, max_stop_loss_pct) = min(0.078, 0.02) = 0.02`，**实际止损永远是 2%**，7.8% 是死参数。

- 场景③（假设去掉封顶、止损=7.8%）证明：7.8% 止损 + 2% 止盈的严重不对称让少数大亏吞掉多数小赚，净亏 -403.46，即便 ETH/SOL 胜率升至 58%–78% 仍亏损。**`max_stop_loss_pct = 0.02` 的封顶是保护性的、正确的**，不应移除。
- 但"锁定了 0.078、实际跑 0.02"会让参数审计、优化器、以及人工读配置都产生误导，应显式收敛。

### 5. 单纯提升止盈不解决胜率问题

场景④（tp2 = 4%）仍净亏 -440.14，XRP/DOGE/ETH 胜率仍为 0%。**止盈空间扩大无法拯救低胜率的追趋势信号**。

### 6. 趋势方向过滤（strength>0.05 禁逆势）是"裸信号的第一道防线"，但与高信号门槛叠加会误杀盈利交易

注入生产 `_confirm_grid_entry` 的趋势方向过滤（`|EMA20-EMA50|/EMA50 > 0.05` 时禁止逆势）后，交叉对比揭示了它的**双重角色**：

- **单独使用（无信号门槛）**：裸网格 -449.70 → -403.21（改善 +46.49，约 10%），胜率 14% → 27%。它把逆势的追跌/追涨开仓转成顺势开仓（交易数 147 → 203），但**仍不足以转正**——它是"第一道防线"，不是"决胜因素"。
- **叠加在高信号门槛之上（0.35）**：+153.46 → **+129.19**（净损 -24.27）。趋势过滤误杀了 XRP、SUI 各 1 笔已被信号质量门槛确认的高质量盈利交易，反而拖累收益。

**结论**：趋势方向过滤的价值是"低质量信号时代的护栏"；当 `min_signal_quality` 已经提到 0.35 之后，它与信号质量门槛存在**功能重叠**，在简化回测中表现为净损。生产是否同样存在这一冗余，需要结合订单簿/成交量确认与多时间框架在真实环境验证，不宜仅凭回测直接移除生产过滤器。

## 五、与生产策略的差异（重要披露）

本回测为**简化单带网格模型**，与生产 `GridStrategy` 存在显著差异：

- 生产有多层网格（grid_count 2–3）+ 非对称方向分配（P32 趋势感知）
- 生产有 `_confirm_grid_entry` 三重确认（成交量 + 订单簿 + 趋势方向）
- 生产有 P33 趋势门禁（ADX>20 + DI 对齐 + 价格位置）
- 生产有 5 维信号质量评分（本回测用 8 指标 `evaluate_signal_quality` 近似，且 rsi 取中性 50 简化）
- 生产有多级止盈（2%/4%/trailing）+ 移动止损 + 保本位 + 波动止损 + 时间离场
- 生产有 P1 磨损型交易过滤器（历史净利为负的币停止开新网格）
- 生产有日内亏损熔断、极端波动暂停、币种健康检查

因此**简化回测的绝对盈亏不直接代表生产策略真实表现**，它量化的是「裸网格均值回归 + taker 手续费」的下限约束，以及信号门槛的相对价值。

## 六、结论与优化建议

**结论**：grid 与 scalping 的亏损主因不同——scalping 死于手续费磨损，grid 死于**裸均值回归信号的极低胜率**。grid 的命门是信号质量门槛（0.35），而非网格间距或手续费。

**优化建议（按优先级）**：

1. **维持 `min_signal_quality ≥ 0.35` 硬下限**（已锁定，本回测再次证实不可下调）。高风时段 ≥ 0.50 亦不可放松。

2. **收敛 `stop_loss_pct` 与 `max_stop_loss_pct` 的冲突**（已执行方案 A）：
   - 已把 `stop_loss_pct` 从 `0.078` 改为 `0.02`，与 `max_stop_loss_pct = 0.02` 对齐，消除"锁定死参数"误导。
   - 该改动不改变实际风控行为（实际止损原本就是 `min(0.078, 0.02) = 2%`），仅让配置语义与运行时一致。

3. **不要把优化资源投在"调间距/降手续费"上**：grid 的 tp/手续费 = 20x，手续费不是瓶颈；`min_grid_spacing` 已 ≥ 0.03，磨损过滤器已生效。

4. **胜率是唯一北极星指标**：任何 grid 参数改动都应先验证"胜率是否 ≥ 52.5% 盈亏平衡线"，再谈盈亏。趋势方向过滤已注入回测并验证（见发现 6）：它是裸信号的第一道防线（-449→-403），但与 0.35 高门槛叠加会误杀盈利交易（+153→+129）。建议在生产真实环境观察它与信号门槛的冗余性，而非仅凭回测直接增删过滤器。
